# 📑 量化投资 AI 平台 Qlib 入门指南

## 1. 什么是 Qlib？
**Qlib** 是微软亚洲研究院（MSRA）开源的量化投资平台。它与传统回测框架最大的区别在于：它是**"AI 原生"**的。它将量化投资的整个流程（数据、特征、模型训练、回测）封装成了标准化的流水线，极大降低了利用深度学习做交易的门槛。

## 2. 核心功能与分工
在生产环境中，Qlib 的典型角色是 **"信号产生器"**：
* **研究阶段（Qlib 擅长）**：处理海量历史数据，训练极其复杂的 AI 模型（如 Transformer, LSTM），生成对未来股价的预测信号。
* **实盘阶段（其他系统擅长）**：将 Qlib 产生的信号接入实盘柜台（如 VnPy、功夫交易），负责实际的下单、风控和撤单。
* **理由**：将"大脑（预测）"与"手脚（执行）"分离，既保证了计算的高性能，也保证了实盘交易的稳定性。

---

## 3. 技术流派：机器学习 vs. 深度学习

| 特性 | 机器学习 (ML) | 深度学习 (DL) |
| :--- | :--- | :--- |
| **形象比喻** | 经验丰富的老师傅 | 观察入微的天才少年 |
| **逻辑** | 依赖人工提取特征（如均线、换手率） | 直接学习原始价格序列，自动提取特征 |
| **优势** | 逻辑清晰、可解释性强、计算速度快 | 上限极高，能捕捉肉眼无法察觉的规律 |
| **硬件要求** | **CPU + 大内存** | **高性能 GPU (NVIDIA)** |

---

## 4. 硬件配置建议 (以用户现有设备为例)
量化研究对硬件的需求具有"分工性"：
* **主力训练机（台式机/RTX 3070）**：显卡算力最强，负责运行复杂的深度学习模型（如 GATS, Transformer）。
* **特征工程机（笔记本/RTX 3060 + 32G内存）**：内存最大，负责全市场海量数据的预处理和机器学习模型（LightGBM）训练，防止内存溢出。
* **策略编写机（M4 Mac Mini）**：能效比高，适合编写代码、查阅文档和远程管理计算任务。

---

## 5. 给新手的行动清单
1.  **从机器学习起步**：优先尝试 Qlib 内置的 `Alpha158` 因子库 + `LightGBM` 模型，这是性价比最高、最易理解的路径。
2.  **关注评价指标**：除了总收益，要重点学习 **IC/IR**（预测能力）和 **最大回撤**（风险控制）。
3.  **跑通示例**：先从沪深300（CSI300）小规模数据开始，熟悉 `qrun` 命令和 `.yaml` 配置文件。
